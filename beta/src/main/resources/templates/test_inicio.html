Proyecto semestral: Visor y editor de procesos

Sistema de gestión de procesos multiempresa: cada organización tiene su espacio propio, usuarios con roles y separación segura de la información.

Resumen breve

Desarrollo incremental que integra persistencia, vistas server-side, servicios REST, frontend interactivo, pruebas, seguridad y despliegue. Permite modelar y editar procesos empresariales (diagramas completos) sin ejecutar instancias reales.

Qué hace el sistema

Empresas y usuarios

Registro de empresas, usuario administrador inicial, alta de colaboradores y roles (admin, editor, lectura). Aislamiento por empresa y control de acceso.

Gestión de procesos

CRUD de procesos con historial, trazabilidad, búsquedas, filtros y eliminaciones lógicas para preservar datos.

Modelado completo

Diagramas con actividades, arcos, gateways, roles, pools, lanes, mensajes y correlación. Validación de coherencia en el editor.

Ejemplo ilustrativo

Solicitud de vacaciones: pool (empresa), lanes (Empleado/Jefe/Talento), actividades (radicar, revisar), gateways decisionales y mensajes de notificación. El diagrama se modela, no se ejecuta.

Alcance

Orientado a visualización y edición (no ejecución). Se modelan y validan todos los elementos; no se integran sistemas externos ni se ejecutan instancias de proceso.
